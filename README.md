# Drift Handling Reset V2.8

Changes:
- Added persistent slip memory to each rear tire.
- Rear grip now falls progressively while spinning/sliding.
- Rear grip recovers slowly rather than snapping back every frame.
- Throttle greatly slows rear-grip recovery.
- Added transition load generated by steering reversal.
- Transition load temporarily increases front authority.
- Transition load temporarily reduces rear grip.
- Transition load adds a chassis yaw torque in the new steering direction.
- Added T% HUD showing active transition load.

Testing:
1. Hold a drift under throttle and check whether rear grip remains consistent.
2. Flick steering into the opposite direction.
3. T% should rise during the transition.
4. The chassis should carry its weight across instead of pausing or snapping straight.
